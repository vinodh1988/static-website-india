# Static Website India

A standalone five-page website made with plain HTML, CSS, and JavaScript.

- `index.html`: India overview and photographic introduction.
- `destinations.html`: five destinations, region filters, search, expandable descriptions, and image viewing.
- `culture.html`: crafts, celebrations, music, and living traditions.
- `food.html`: regional Indian food traditions.
- `journeys.html`: two illustrative itineraries, duration selection, and printing.

Open `index.html` directly in a browser. All page links, photographs,
stylesheets, scripts, and icons use local relative paths. No installation,
framework, build step, or development server is needed.

`styles.css` and `extras.css` provide the responsive layout. `script.js`
handles navigation, photographs, destination filters, and journey controls.
Local assets and their source credits are in `assets/`.

Content is an independent introduction to India. Journey ideas are
illustrative, not booking services or fixed transport schedules. Further
destination information is available from Incredible India, Kerala Tourism,
and Goa Tourism. Photographic and Lucide icon credits are in
`assets/CREDITS.md`.
